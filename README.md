# AI 搜索主入口转化报告

从京东「日维度_搜索方式转化情况」Excel 中提取指定搜索方式的关键指标，生成带格式的汇总 Excel。

## 功能

从源 Excel 中提取以下 6 种 AI 搜索方式的数据：

1. 手动文字-AI搜
2. 底纹词-AI搜
3. 语音输入-AI搜
4. 试试这样问-AI搜
5. 你最近问过-AI搜
6. 推荐词-前置页-AI搜

提取字段包括：搜索pv、搜索uv、总提问条数、直接订单数。

## 使用方法

```bash
# 安装依赖
pip install -r requirements.txt

# 提取全部日期数据
python3 scripts/extract_conversion.py <excel文件路径>

# 提取指定日期范围
python3 scripts/extract_conversion.py <excel文件路径> <起始日期> <结束日期>
```

日期格式为 YYYYMMDD（如 20260907）。不指定日期时自动提取源文件中全部日期。

输出文件保存到 `outputs/` 目录，文件名格式为 `搜索方式转化情况_<起始>-<结束>.xlsx`。

## 输出格式

| 日期 | 搜索方式 | 搜索pv | 搜索uv | 总提问条数 | 直接订单数 |
|------|---------|-------|-------|-----------|-----------|

按日期升序、搜索方式固定顺序排列，表头加浅蓝底色和粗体，所有单元格居中并加边框。

## 注意事项

- 源 Excel 的日期列（A 列）存在合并单元格，脚本通过向下填充处理
- 源 Excel 的「搜索分类」列（B 列）中，目标搜索方式的分类为「主入口」
- 脚本直接按「搜索方式」列（C 列）匹配，不依赖分类列
